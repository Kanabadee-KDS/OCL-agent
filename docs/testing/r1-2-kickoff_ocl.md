## 6. กติกา 5 ข้อ

1. กรอก **ผู้ทดสอบ** และ **วันที่** ทุกแถวที่ทำ · issue ทุกแถวมี **วันที่พบ ผู้พบ สถานะ = เปิด**
2. "ไม่ผ่าน" ต้องเขียน **ที่คาด vs ที่ได้** ในช่องผลจริง (หมวด C ใส่ตัวเลขทั้ง 10 ส่วน) ไม่ใช่คำว่า "ไม่ตรง"
3. **ห้ามแก้** ช่องผลที่คาดหวังหรือภาคผนวก ก ถ้าไม่ตรง → เปิด issue ประเภท `ฟังก์ชัน` "ค่าที่คาดหวังไม่ตรง"
4. **ไม่ต้องแนบภาพ** · เขียนสิ่งที่เห็นเป็นข้อความ และใส่ **เลขงาน 12 ตัวจาก URL** ในหมายเหตุทุกกรณีที่สร้างหรือเปิดงาน
5. Issue ID ไม่ซ้ำ · ลบแถวตัวอย่าง `EX-00` และ `ISS-000` ก่อนส่ง
