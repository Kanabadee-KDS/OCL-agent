## 4. วิเคราะห์กรณีที่ไม่ผ่าน

### 4.1 B-2 / ISS-0 · ไฟล์ว่างผ่านเข้าหน้าตรวจ — **บั๊กจริง ความรุนแรง: ปานกลาง**

- สิ่งที่ทีมเห็น (iss0.jpg): อัปโหลด `x.docx` แล้วไปถึงหน้า "ตรวจสอบข้อมูลที่ AI สกัดได้" แสดง "ฟิลด์ 34 · ว่าง 34" และ "ต้นฉบับ · หน้า –"
- ตรวจกับโค้ด: `api/imports.py` มีด่าน `if not data: raise HTTPException(400, "ไฟล์ว่าง")` อยู่แล้วและทำงานกับไฟล์ **0 byte** · แต่ไฟล์ที่ทีมใช้เป็น Word เปล่าที่บันทึกจากโปรแกรม (ขนาด ~1 KB มีโครง OOXML แต่ไม่มีข้อความ) จึงผ่านด่านนี้ ingest ได้ 1 หน้าว่าง extract ได้ทุกส่วนเป็น 0/None และ checks ขึ้น `fail` 7 ข้อ แต่ worker ยังตั้งสถานะงานเป็น `review` ตามปกติ
- ทำซ้ำบนโค้ดปัจจุบันได้ 100% (`ocl extract --no-llm` กับ docx เปล่า 1,255 byte → ทุกส่วน 0, fail 7)
- ข้อสรุป: ระบบขาดด่าน "ไม่พบเนื้อหา" หลัง ingest · ควรให้งานจบเป็น `failed` พร้อมข้อความ เช่น "ไม่พบเนื้อหาในไฟล์ (0 หน้า / ไม่มีข้อความ)" แทนที่จะเปิดหน้าตรวจเปล่า · ความรุนแรงที่ทีมให้ว่า "สูง" ปรับเป็น "ปานกลาง" เพราะผู้ใช้เห็นทันทีว่าว่างและไม่ทำให้ข้อมูลอื่นเสียหาย · test case ต้องแยกเป็น 2 กรณี: ไฟล์ 0 byte (ด่านเดิม) กับ Word/PDF ที่ไม่มีข้อความ (ด่านใหม่)

### 4.2 C-1, C-2, C-3 / ISS-2 · ตัวเลขและ checks ไม่ตรงชีต "ค่าที่คาดหวัง" — **ไม่ใช่บั๊ก: ชีตค่าที่คาดหวังไม่ครบ**

- ตัวนับ "ข้อมูลหลัก 34" (iss1/iss2.jpg) vs ชีต 33: ชีตนับ *ฟิลด์ที่มีค่า* (33) ส่วนหน้าจอนับ *ฟิลด์ทั้งหมด* (34 = 33 มีค่า + 1 ว่าง ตามป้าย "ว่าง 1") ตัวเลขเดียวกันแค่นิยามต่างกัน
- "check ขาด: ไม่มีคำอธิบาย 2 วิชา (สพท682, ปพท691)": รันโค้ดปัจจุบันได้ warn `course_fields` ข้อนี้เหมือนกันทุกตัวอักษร ระบบทำงานถูก แต่ชีตไม่ได้ใส่ไว้ · รายการที่ทีมเติมเข้าชีตเอง (ปร.ด. 3 ข้อ, ศศ.บ. 4 ข้อ, ศศ.ม. 1 ข้อ) ตรงกับผลรันวันนี้ทุกข้อ แปลว่าไม่มี regression
- C-2 บันทึกแค่ "ไม่ตรง" ไม่ระบุว่าส่วนไหน ตัวเลขเท่าไร ตามคู่มือต้องบันทึกตัวเลขที่ได้ จึงใช้ยืนยันอะไรไม่ได้
- ทีมแก้ชีต "ค่าที่คาดหวัง" ด้วยตัวเอง (คอลัมน์ที่กำหนดว่าห้ามแก้) ทำให้ผลกับเฉลยปนกัน · ครั้งต่อไปให้เปิด issue แทนการแก้เฉลย
- สาเหตุราก: ค่าที่คาดหวังเขียนด้วยมือจากผลรันครั้งหนึ่ง พอโค้ดเปลี่ยน (checks ใหม่ `course_fields`, `course_conflicts`, PLO แยกแผน) เฉลยก็ล้าสมัยทันที → ต้องสร้างเฉลยจากโค้ดด้วยสคริปต์ (WP2)

### 4.3 D-1 / ISS-1 · ฟิลด์ 34 ไม่ใช่ 35 — **ไม่ใช่บั๊ก: test script ผิด**

`extract/info.py` ประกาศ `FIELDS` = 34 รายการ หน้าจอแสดง 34 ถูกต้อง · `test-script_ocl.csv` ฉบับปัจจุบัน (D-01) เขียน "34–35" ให้แก้เป็น 34

### 4.4 ข้อสังเกตเพิ่มจากหลักฐาน

- ศศ.บ. จำนวนหน้าในชีตถูกแก้จาก 221 เป็น 214 — ยังไม่ทราบว่าเกิดจากไฟล์เล่มคนละเวอร์ชันหรือการนับหน้าของ ingest เปลี่ยน ต้องตรวจบน build ปัจจุบัน
