## 1. ทำไมต้องทดสอบชุดนี้

ตัวเลขความถูกต้องทั้งหมดที่ผ่านมา (รายงาน E2 และ deck นำเสนอลูกค้า) วัดโดยเทียบกับ **ค่าอ้างอิงที่ Extraction Engine สร้างเอง** ซึ่งยังไม่มีใครเทียบกับเล่มจริง ตัวเลขชุดนั้นจึงบอกได้แค่ว่า "แบบจำลองไม่ทำข้อมูลเสีย" แต่ยังไม่บอกว่า "ระบบถูกต้องตามเล่มกี่ %"

การทดสอบนี้ให้ทีมสร้าง **เฉลยจากเล่มจริง** แล้ววัด 4 ชุดเทียบกับเฉลยเดียวกัน

| คอลัมน์ในไฟล์ | ชุดที่วัด | ที่มาของค่า |
|---|---|---|
| ระบบจริง | กระบวนการที่ใช้งานจริง (Extraction Engine + แบบจำลอง) ทุกแบบจำลองได้ค่าเดียวกัน | `docs/eval/run-2026-10-23-localllm-fewshot/<เล่ม>/ollama-parser_first` |
| Local LLM ล้วน | แบบจำลองสกัดเองทั้งหมด | `…-localllm-fewshot/<เล่ม>/ollama-llm_only` |
| Local LLM (ปรับปรุง) ล้วน | แบบจำลองสกัดเองทั้งหมด พร้อมการปรับปรุง (ผลเบื้องต้น) | `…-localllm-fewshot/<เล่ม>/ollama-llm_only-fs-all` |
| Gemini ล้วน | แบบจำลองสกัดเองทั้งหมด (รอบประเมินแรก) | `docs/eval/run-2026-10-23/<เล่ม>/gemini-llm_only` |

ค่าในไฟล์คัดลอกมาจากผลที่บันทึกไว้แล้ว ทีมไม่ต้องรันระบบเอง

ผลที่ได้จะใช้แทนตัวเลขเดิมในรายงานและ deck (สไลด์ 5, 6, 10)

## 5. ขั้นตอน

### ระยะ 0 · เตรียม (PM ราว 30 นาที)

1. ส่งเล่มต้นฉบับและไฟล์ CSV ให้ผู้ตรวจ พร้อมตารางแบ่งงานในข้อ 4
2. ผู้ตรวจเปิด CSV ใน Excel แล้ว Save As เป็น `accuracy_<ชื่อผู้ตรวจ>.xlsx`
3. กรองคอลัมน์ B ให้เหลือเฉพาะเล่มของตัวเอง
4. อ่านกฎข้อ 8.3 ของ `test-manual_ocl.md` และแถวตัวอย่าง EX-00

### ระยะ 1 · สร้างเฉลยจากเล่มจริง (วันที่ 1)

**ก่อนเริ่ม ซ่อนคอลัมน์ H–O** โดยเลือกหัวคอลัมน์ H ถึง O แล้วคลิกขวา > Hide ระหว่างระยะนี้ห้ามเปิดดู เพราะถ้าเห็นคำตอบของระบบก่อน จะเผลอเชื่อตามและเฉลยจะไม่เป็นอิสระ

กรอกคอลัมน์ G ทีละแถว โดยเปิดเล่มไปที่หน้าในคอลัมน์ F หรือค้นหาด้วย Ctrl/Cmd+F

| ส่วน | กรอกอะไร | ข้อควรระวัง |
|---|---|---|
| ข้อมูลหลัก | ค่าตามเล่ม เช่น `127` หรือ `วท.บ. (วิทยาการการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม)` | เล่มเขียน xxxx หรือไม่มีค่า ให้กรอก `(ว่าง)` · ระยะเวลาให้ดูช่องที่มีเครื่องหมาย ☑ ไม่ใช่ช่องแรกที่เห็น · ตัวเลขกรอกเป็นเลขอารบิก |
| PLO | ข้อความ PLO เต็ม รวมส่วนที่ขึ้นบรรทัดใหม่ | ปร.ด. PLO2 และ PLO3 เขียนต่างกันระหว่างรายการกับตาราง K/S/E/C ให้กรอกตามรายการ แล้วจดข้อความในตารางลงคอลัมน์ R |
| โครงสร้างหลักสูตร | `ชื่อหมวด · หน่วยกิต` เช่น `หมวดวิชาศึกษาทั่วไป · 24` | หมวดที่เล่มไม่ระบุหน่วยกิต ให้กรอก `ชื่อหมวด · (ว่าง)` |
| รายวิชา · ชื่อวิชาภาษาไทย | ชื่อวิชาตามเล่ม | ค้นด้วยรหัสในคอลัมน์ D · ชื่อในรายการรายวิชากับในคำอธิบายรายวิชาอาจต่างกัน ให้ใช้ชื่อในรายการรายวิชา และจดอีกชื่อลงคอลัมน์ R |
| รายวิชา · หน่วยกิต | รูปแบบ `x(a-b-c)` เช่น `3(3-0-6)` | ต้องครบทั้ง 4 ตัวเลข |
| รายวิชา · จำนวนรายวิชาทั้งหมดในเล่ม | จำนวนรหัสวิชาทั้งหมดในหมวด 4 ข้อ 3 | นับเฉพาะรายการรายวิชา อย่านับซ้ำในส่วนคำอธิบาย · จดวิธีนับในคอลัมน์ R เช่น "นับจากตารางรายวิชา หน้า 26–30" |
| เล่มสแกน | อ่านจากภาพใน PDF สแกน | ค่าที่ถูกคือค่าตามภาพที่เห็น |

กรอกคอลัมน์ P และ Q ทุกแถว

กรณีหาไม่เจอหรือไม่แน่ใจ ให้กรอกค่าที่คิดว่าถูก แล้วเขียน "ไม่แน่ใจ: <เหตุผล>" ในคอลัมน์ R

### ระยะ 2 · ตัดสินผล (วันที่ 2 ช่วงเช้า)

เริ่มระยะนี้ได้เมื่อกรอกคอลัมน์ G **ครบทุกแถวแล้วเท่านั้น** จากนั้น Unhide คอลัมน์ H–O แล้วกรอกช่องผล I · K · M · O ของทุกแถว

| ใส่ | เมื่อ |
|---|---|
| `ตรง` | ค่าเหมือนเล่มตามกฎ 8.3 (ไม่นับช่องว่างซ้ำ การขึ้นบรรทัด หรือช่องว่างรอบวงเล็บ) |
| `ไม่ตรง` | สะกดต่าง สระหรือวรรณยุกต์หาย ตัวเลขต่าง ขาดหรือเกินคำ หรือข้อความถูกเรียบเรียงใหม่แม้ความหมายเดิม |
| `ไม่ตรง` | ช่องเป็น `(ว่าง)` แต่เล่มมีค่า (ตกหล่น) หรือเล่มไม่มีค่าแต่ช่องมีค่า (แต่งเพิ่ม) |
| `ไม่ตรง` | ช่องเป็น `(ไม่พบ)` |
| `ก้ำกึ่ง` | ตัดสินไม่ได้ ให้เขียนเหตุผลในคอลัมน์ R แล้ว PM ตัดสิน |
| เว้นว่าง | แถวที่หมายเหตุระบุว่าไม่คิดคะแนน (รายวิชาปริญญาโทและเอกในคอลัมน์ "ล้วน") |

ตัวอย่าง:

| สถานการณ์ | ผล |
|---|---|
| เล่ม `127` · ชุดได้ `127` | ตรง |
| เล่ม `127` · Local LLM ล้วนได้ `(ว่าง)` | ไม่ตรง |
| เล่มสแกน: เล่ม "วิทยาศาสตรบัณฑิต" · ชุดได้ "วทยาศาสตรบัณฑิต" (สระหาย) | ไม่ตรง |
| เล่ม `(ว่าง)` (รหัสหลักสูตร xxxx) · ชุดได้ `(ว่าง)` | ตรง |
| เล่ม "หลักการเก็บข้อมูลทางชุมชนและสังคม" · ชุดได้ "หลักการเก็บข้อมูลชุมชนและสังคม" | ไม่ตรง |
| PLO ขึ้นบรรทัดใหม่กลางประโยคในเล่ม แต่ชุดได้ข้อความต่อกันครบ | ตรง |

**ทุกแถวที่คอลัมน์ I (ระบบจริง) = `ไม่ตรง`** ให้เปิด issue 1 แถวใน `issue-log_ocl.csv`
- TC_ID: รหัสแถว เช่น `ACC-063`
- ประเภท: `ข้อมูลสกัดผิด`
- เล่ม · ส่วน · รายการ (รหัส/ฟิลด์) · ค่าในระบบ · ค่าในเล่ม · หน้าในเล่ม: คัดลอกจากแถวนั้น (คู่มือหลักข้อ 10 บังคับกรอกเมื่อประเภทเป็นข้อมูลสกัดผิด)
- โมเดล: `ระบบจริง`
- ความรุนแรง: ตามคู่มือหลักข้อ 10

ค่าในคอลัมน์ I คือสิ่งที่ผู้ใช้จะได้รับจริง ส่วนคอลัมน์ K · M · O ("ล้วน") ไม่ต้องเปิด issue เพราะใช้วัดขีดความสามารถของแบบจำลองเท่านั้น

### ระยะ 3 · ตรวจไขว้ (วันที่ 2 ช่วงบ่าย ราว 1 ชั่วโมง)

เพื่อยืนยันว่าเฉลยเชื่อถือได้ ให้แต่ละคนตรวจเฉลยของคนถัดไป (คนที่ 1 ตรวจคนที่ 2, คนที่ 2 ตรวจคนที่ 3, คนที่ 3 ตรวจคนที่ 1)

1. ตรวจเฉพาะแถวที่ TC_ID ลงท้ายด้วย 0 (ACC-010, ACC-020, …) ที่อยู่ในเล่มของอีกคน
2. เปิดเล่มแล้วอ่านค่าเอง จากนั้นเทียบกับคอลัมน์ G ของอีกคน
3. ถ้าตรงกัน ไม่ต้องทำอะไร ถ้าไม่ตรงกัน ให้คุยกันแล้วแก้คอลัมน์ G และช่องผลที่เกี่ยวข้อง พร้อมจดในคอลัมน์ R ว่า "แก้หลังตรวจไขว้: <ค่าเดิม> → <ค่าใหม่>"
4. ถ้าเล่มใดต้องแก้หลังตรวจไขว้เกิน 2 แถว ให้เจ้าของเล่มทบทวนเล่มนั้นทั้งเล่มอีกรอบ

### ระยะ 4 · รวมผล (PM ราว 1 ชั่วโมง)

1. รวม 3 ไฟล์เป็นไฟล์เดียว เรียงตาม TC_ID
2. ตัดสินทุกแถวที่เป็น `ก้ำกึ่ง` ให้เป็น `ตรง` หรือ `ไม่ตรง` แล้วจดเหตุผลในคอลัมน์ R
3. คำนวณความถูกต้องของแต่ละชุด ตัวอย่างสำหรับระบบจริง (คอลัมน์ I):

```text
=COUNTIF(I:I,"ตรง") / (COUNTIF(I:I,"ตรง") + COUNTIF(I:I,"ไม่ตรง"))
```

ทำแบบเดียวกันกับคอลัมน์ K (Local LLM ล้วน), M (Local LLM ปรับปรุง ล้วน) และ O (Gemini ล้วน) โดยไม่นับแถว EX-00

4. ทำ Pivot Table (แถว = ส่วน, คอลัมน์ = ผลของแต่ละชุด) เพื่อดูว่าชุดไหนพลาดที่ส่วนไหน
5. ดูแถว "จำนวนรายวิชาทั้งหมดในเล่ม" ถ้าจำนวนของระบบต่างจากเล่ม แปลว่ามีวิชาตกหล่นหรือแต่งเพิ่ม ให้หาว่าวิชาไหน แล้วเปิด issue ความรุนแรงสูง
6. ส่งไฟล์รวมให้ผู้พัฒนา เพื่อเขียนรายงานความถูกต้องเทียบเล่มจริง และแก้ตัวเลขใน deck

## 7. คำถามที่พบบ่อย

**ทำไมต้องซ่อนคอลัมน์ H–O ก่อน**
ถ้าเห็นคำตอบของระบบก่อน คนมักอ่านเล่มแล้วรู้สึกว่าตรง ทั้งที่ระบบผิดเล็กน้อย เช่น สระหาย 1 ตัว เฉลยต้องมาจากเล่มเท่านั้น

**ระบบได้ค่าถูก แต่หน้าในคอลัมน์ F ผิด ต้องทำอย่างไร**
ไม่มีผลต่อผลการตรวจ การทดสอบนี้ตรวจเฉพาะค่า ไม่ตรวจเลขหน้า (เลขหน้าตรวจในหมวด V ของรอบทดสอบหลัก)

**ชุดหนึ่งได้ `(ไม่พบ)` แต่เป็นรายวิชาปริญญาโทหรือเอก**
ถ้าหมายเหตุระบุว่าไม่คิดคะแนน ให้เว้นช่องผลว่าง เพราะแบบจำลองล้วนอ่านเฉพาะย่อหน้า และรายวิชาของเล่มกลุ่มนี้อยู่ในตาราง จึงไม่ใช่ข้อผิดพลาดของแบบจำลอง

**เล่มเขียนค่าเดียวกันต่างกันสองที่ ใช้ค่าไหน**
ใช้ค่าในตำแหน่งหลักตามที่ระบุในคอลัมน์ E (เช่น PLO ใช้รายการ, ชื่อวิชาใช้รายการรายวิชา) แล้วจดอีกค่าในคอลัมน์ R ผู้พัฒนาจะส่งให้ Admin ตัดสินว่าฉบับไหนเป็นฉบับทางการ

**เจอข้อผิดที่ไม่มีแถวในไฟล์ (เช่น วิชาที่ไม่อยู่ในตัวอย่าง)**
เปิด issue ใน `issue-log_ocl.csv` ได้ตามปกติ แต่ไม่ต้องเพิ่มแถวในไฟล์นี้ เพื่อให้ทุกชุดถูกวัดด้วยรายการเดียวกัน

**ทำไม Gemini เป็นผลรอบแรก**
ไฟล์นี้ใช้ผลที่บันทึกไว้แล้ว Gemini ยังไม่ได้วัดซ้ำด้วยโค้ดปัจจุบัน ถ้าผู้พัฒนาวัดซ้ำก่อนเริ่มทดสอบ จะออกไฟล์ฉบับใหม่ให้
