## 6. วิธีเปิดและกรอก CSV

**เปิดไฟล์**
- **Excel**: ดับเบิลคลิกเปิดได้เลย ภาษาไทยแสดงถูก (ไฟล์เป็น UTF-8 มี BOM) ถ้าเห็นตัวอักษรเพี้ยน ใช้ Data → From Text/CSV → File origin `65001: Unicode (UTF-8)`
- **Google Sheets** (แนะนำเมื่อหลายคนกรอกพร้อมกัน): File → Import → Upload → Replace spreadsheet → Separator: Comma
- ตั้ง Filter ที่แถวหัวตาราง แล้วกรองคอลัมน์ "ผู้ทำ" หรือ "หมวด" ให้เหลือเฉพาะงานของตัวเอง

**คอลัมน์ที่ห้ามแก้** (คอลัมน์ 1–12): TC_ID · หมวด · หัวข้อทดสอบ · ประเภท · ความสำคัญ · ผู้ทำ · บัญชี/บทบาท · เงื่อนไขก่อนทดสอบ · ขั้นตอน · ข้อมูลทดสอบ · ผลที่คาดหวัง · วิธีตรวจ/หลักฐานที่ต้องเก็บ

ถ้าเห็นว่าขั้นตอนหรือผลที่คาดหวังผิด อย่าแก้ในช่องนั้น ให้เขียนในช่อง "หมายเหตุ" และแจ้ง PM

**คอลัมน์ที่ต้องกรอก** (6 คอลัมน์ท้าย):

| คอลัมน์ | กรอกอะไร | ตัวอย่าง |
|---|---|---|
| ผลจริง | สิ่งที่เห็นจริง ใช้รูปแบบที่ระบุในคอลัมน์ "วิธีตรวจ" | `30 · 12/5 · 1/50 · 5 · 53 · 5 · 16 · 57 · 57/57 · 3/0` |
| สถานะ | เลือกหนึ่งคำ พิมพ์ให้ตรงทุกตัวอักษร | `ผ่าน` / `ไม่ผ่าน` / `บล็อก` / `ข้าม` |
| ผู้ทดสอบ | ชื่อเล่นหรือชื่อจริง ใช้ชื่อเดิมตลอดรอบ | `สมชาย` |
| วันที่ทดสอบ | วว/ดด/ปปปป (พ.ศ.) | `24/10/2569` |

แถว `EX-00` เป็นตัวอย่างการกรอก ลบได้

**ความหมายของสถานะ**

| สถานะ | ใช้เมื่อ |
|---|---|
| ผ่าน | ผลจริงตรงกับผลที่คาดหวังทุกข้อ |
| ไม่ผ่าน | ผลจริงต่างจากที่คาดหวังแม้เพียงข้อเดียว ต้องเปิด issue ทุกครั้ง |

## 8. วิธีตรวจความถูกต้องกับเล่มจริง (หมวด V และ M) อย่างละเอียด

หมวดนี้ต่างจากหมวดอื่น เพราะผู้ทดสอบต้องเทียบค่าที่ระบบสกัดกับเล่มต้นฉบับทีละรายการ

### 8.1 เตรียมหน้าจอ

- เปิดหน้าตรวจของงานเล่มนั้น (งานที่อ่านด้วยกฎจากหมวด C)

### 8.2 ขั้นตอนต่อหนึ่งแถวของหมวด V

1. เปิดส่วนที่ระบุ (เช่น "ส่วนที่ 8 รายวิชา")
2. **นับจำนวน** รายการในส่วนนั้น (ตัวนับหัวตาราง) เทียบกับ "จำนวนรายการ = …" ในผลที่คาดหวัง
3. **เลือกตัวอย่าง** ตามขนาดที่ระบุในขั้นตอน (ข้อ 8.4)
4. ต่อหนึ่งรายการ:
   - คลิกป้ายชื่อฟิลด์หรือแถว ให้แผงต้นฉบับไปหน้าที่อ้าง
   - ตรวจว่าหน้าที่อ้างมีค่านั้นจริง (ตรวจการอ้างหน้า)
   - เปิดเล่มจริงตำแหน่งเดียวกัน แล้วเทียบค่าตามกฎข้อ 8.3
5. นับผล แล้วกรอกช่องผลจริงรูปแบบ `ตรวจ N ถูก M ผิด K` เช่น `ตรวจ 20 ถูก 19 ผิด 1`
6. ทุกค่าที่ผิด เปิด 1 แถวใน `issue-log_ocl.csv` ประเภท "ข้อมูลสกัดผิด" (ข้อ 10)
7. สถานะ: **ผ่าน** เมื่อจำนวนรายการตรงและผิด 0 · **ไม่ผ่าน** เมื่อจำนวนต่างหรือมีค่าผิดอย่างน้อย 1

## 11. การส่งผลและสรุปรายวัน

**ทุกวันก่อน 17:00** แต่ละคนส่ง CSV ที่กรอกแล้ว (หรืออัปเดต Google Sheets กลาง) + issue ที่เปิดใหม่ แล้วแจ้งในแชตทีมด้วยสรุป 3 บรรทัด:

```
วันที่ 24/10/2569 · สมชาย
ทำแล้ว 18 กรณี: ผ่าน 15 ไม่ผ่าน 2 บล็อก 1
issue ใหม่: ISS-003 (สูง), ISS-004 (กลาง) · บล็อก K-04 เพราะยังไม่มีบัญชี faculty
```

**สูตรสรุปใน Google Sheets/Excel** (สมมติชีตชื่อ `test`, คอลัมน์ B = หมวด, N = สถานะ)

```
ผ่านของหมวด V          =COUNTIFS(test!B:B,"V*",test!N:N,"ผ่าน")
ไม่ผ่านทั้งหมด          =COUNTIF(test!N:N,"ไม่ผ่าน")
ยังไม่ได้ทดสอบ          =COUNTA(test!A:A)-COUNTA(test!N:N)
issue สูงขึ้นไปที่ยังเปิด  =COUNTIFS(issue!F:F,"สูง",issue!T:T,"<>ปิด")+COUNTIFS(issue!F:F,"วิกฤต",issue!T:T,"<>ปิด")
```

**ความแม่นยำต่อส่วน (หมวด V)** PM รวมจากช่องผลจริง `ตรวจ N ถูก M ผิด K` ของ 5 เล่ม: ความแม่นยำส่วนนั้น = ΣM ÷ ΣN แยกตามส่วน 1–10

3. หมวด M: ครบ 12 แถว และไม่มีการแต่งข้อมูล (ความรุนแรงสูง) ที่ยังไม่ได้อธิบาย
