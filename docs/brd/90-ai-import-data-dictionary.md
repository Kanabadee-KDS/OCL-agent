# 90 Data dictionary: 10 ส่วนที่ AI สกัดจากเล่มหลักสูตร

> ฐานของ JSON schema (pydantic) ในเฟส D4 · ที่มา: หน้า `#/import` และ `#/import-review` ของ mock + เล่มตัวอย่าง 5 เล่ม
> ทุกฟิลด์ในทุกส่วนมี metadata เดียวกัน: `value` · `confidence` (high/medium/low) · `source` `{page, snippet}` · `inferred` (true เมื่อเล่มไม่ได้เขียนตรง ๆ) · `ocr_fixed` (รายการคำที่แก้)

ลำดับการนำเข้าและความมั่นใจเริ่มต้นตามแหล่งที่มา: parse ตรงจากตาราง docx = สูง · LLM สกัดจากข้อความ = กลาง · อนุมาน = ต่ำ

## ข้อเสนอแนะเพิ่มเติม (`suggestions`, ไม่บันทึกอัตโนมัติ)

- `skills`: ทักษะที่เล่มระบุ (หมวด 5 ข้อ 2.1) + ผู้สมัครใน Skill DB
- `ylo`: ผลลัพธ์การเรียนรู้รายชั้นปี + รหัส KSEC ที่อ้าง
- `study_plans`: แผนการศึกษา ปี/ภาค → รายวิชา (ใช้ใน M3)

## หัวข้อที่ไม่นำเข้าเป็นฟิลด์ (แต่มีใน Markdown ทั้งเล่ม)

ปรัชญา/วัตถุประสงค์/ความสำคัญ (หมวด 2 ข้อ 1–2) · คุณสมบัติผู้เข้าศึกษา · ปัญหานิสิตแรกเข้าและกลยุทธ์ · งบประมาณ · การเทียบโอน · สถานที่ · หมวด 6–8 · ภาคผนวก

## หมายเหตุจากเล่มตัวอย่าง (ingest D2)

- เล่ม docx ทั้ง 4 ไม่ใช้ Heading style → ตัดหมวดด้วย pattern "หมวดที่ N" และตัวหนา (ทำแล้ว)
- จุด ● ใน Mapping เป็น Wingdings (F09F, F06C) · ☑/□ ใน "รูปแบบของหลักสูตร" เป็น Wingdings FE/6F → แปลงเป็น Unicode แล้ว นับได้ (เล่มภูมิอากาศ: ● 190 ☑ 8 □ 6)
- Mapping 4.1 เป็นตารางหัว 2 แถว (แถวแรก merge "ผลลัพธ์การเรียนรู้ของหลักสูตร") → parser ต้องใช้แถวที่ 2 เป็นชื่อคอลัมน์ PLO
- เล่ม ป.เอก/ป.โท โครงสร้างต่างจาก ป.ตรี (แผน ก/ข, วิทยานิพนธ์) → schema `structure` ต้องเป็น tree ไม่ใช่ฟอร์มตายตัว
- PDF (เล่มอาหาร 186 หน้า): text layer ใช้ได้ · PyMuPDF `find_tables` พบ 119 ชิ้น merge เหลือ 88 · ข้อความในเซลล์ต้องอ่านตามลำดับ content stream (การเรียงตามตำแหน่งทำให้สระ/วรรณยุกต์ไทยกระจัดกระจาย) · glyph ยืนยันจากภาพหน้าจริง: Wingdings FE = ☑, 9F/6C = ●, Wingdings 2 A3 = □ · หน้า 103 เป็นสแกน (ไม่มี text) ระบบ render เป็นรูปไว้ให้ OCR ภายหลัง
- R1 ส่วนที่ 9 (21 ต.ค.): Mapping 4.1 สกัดด้วย parser ล้วนจากตารางที่มี ● (รวมตารางแยกต่อกลุ่มของ ป.เอก) ตาราง 4.2 (PLO×KSEC เป็นตัวเลข) ถูกข้ามไว้รอส่วนที่ 5 · เล่ม ศศ.บ. มี PLO6 ในหมวด 3 แต่ตาราง 4.1 มีถึง PLO5 → validator `mapping_has_all_plos` เตือน
- R1 ส่วนที่ 1 (21 ต.ค.): `info` อ่านจากหน้าปก (ฉบับ พ.ศ./ใหม่-ปรับปรุง/คณะ) + หมวด 1 ข้อ 1–7, 10, 13 ด้วย parser ล้วน ได้ 30–34 จาก 35 ฟิลด์ทั้ง 5 เล่ม (เล่มภูมิอากาศยังไม่ใส่รหัส สกอ. = xxxx) · ช่องติ๊ก ☑/☒/✔ นับเป็นเลือก, □/■ ไม่เลือก (เล่ม ศศ.ม. พิมพ์ตัว R ในฟอนต์ Wingdings 2 → ingest แปลงให้แล้ว) · เล่มใส่เลขข้อย่อยผิด (ศศ.ม. มี 5.5 สองข้อ) จึงยึดคำในหัวข้อแทนเลข · ฟิลด์อนุมาน 7 ฟิลด์ติดธง `inferred` (ระดับ กลุ่มการศึกษา ภาคที่นับ นานาชาติ ประเภทรับสมัคร เกณฑ์มาตรฐาน CWIE) · LLM ถูกเรียกเฉพาะเมื่อฟิลด์ข้อความยังว่างและรับเฉพาะค่าที่ปรากฏตรงตัวในหมวด 1 (กับ 5 เล่มนี้ไม่ถูกเรียกเลย) · validator: `info_required` `program_code_format` `info_credits_match` `name_consistent` `next_revision` `info_inferred` · มติอนุมัติ (ข้อ 13 บรรทัด "ได้รับอนุมัติ...") ยังไม่สกัด รอส่วนที่ 10
