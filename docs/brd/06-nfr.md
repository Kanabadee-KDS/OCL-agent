# 06 Requirement ที่ไม่ใช่ฟังก์ชัน (NFR)

> ร่าง 28 ต.ค. 2569 · ทุกข้อมีเกณฑ์ที่วัดได้ วิธีวัด และผลล่าสุด · ป้าย **[เสนอ]** = เกณฑ์ที่คณะผู้พัฒนาเสนอจากผลวัด ต้องให้ลูกค้ายืนยัน · ป้าย **[ยืนยันแล้ว]** = มาจาก mock, TOR, developer prompt หรือข้อห้ามของ server ที่ตกลงแล้ว · กรณีทดสอบอ้างจาก `docs/testing/test-script_ocl.csv` · ตารางไล่ความครบใน `91-traceability.md`

## 3. ความปลอดภัยและสิทธิ์

| NFR-14 | เข้าถึงระบบได้เฉพาะในเครือข่ายที่กำหนด | v1 ผ่าน Tailscale เท่านั้น เปิดพอร์ตเดียว `100.104.172.122:8100` ไม่เปิด 5432/3000/8000 สู่ 0.0.0.0 **[ยืนยันแล้ว]** (B5 · `docs/server-constraints.md`) | `ss -tlnp` บน server | ตั้งค่าใน `deploy/docker-compose.yml` แล้ว · ยังไม่ได้ตรวจด้วย `ss` ในรอบ R1-2 (หมวด S) | S-03 |

## 8. เกณฑ์ที่ต้องให้ลูกค้ายืนยัน
