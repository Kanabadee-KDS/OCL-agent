## เพิ่ม 22 ต.ค. 2569 (จากการทำ auth)

- **A9 ชื่อโดเมนสำหรับระบบ**: Google OAuth ไม่รับ redirect URI ที่เป็น IP (100.104.172.122) จึงเปิด Google SSO บน server ไม่ได้จนกว่าจะมีชื่อโดเมน + HTTPS (ทางเลือก: โดเมนของ มศว ที่ชี้มาที่ server · หรือ Tailscale MagicDNS + `tailscale cert` สำหรับช่วงทดสอบ) · ระหว่างนี้ใช้บัวศรีไอดี+รหัสผ่านที่ผู้ดูแลตั้งให้ในระบบนี้
- **A10 การยืนยันบัวศรีไอดีจริง**: ปัจจุบันเก็บรหัสผ่านในตาราง users ของระบบเอง (POC) ต้องการทราบว่าให้ต่อ LDAP/API ของสำนักคอมพิวเตอร์ หรือใช้ Google SSO อย่างเดียว
