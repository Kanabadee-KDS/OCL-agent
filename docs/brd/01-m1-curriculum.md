# 01 M1 บริหารข้อมูลหลักสูตร

เมนูใน mock: แดชบอร์ดหลักสูตร `#/dash-cur` · คู่มือหลักสูตรตาม TOR `#/cur` `#/cur-edit/<id>` · ตรวจสอบและบันทึก PLO โดยคณะ `#/fac-plo` `#/fac-plo-edit/<id>` · งานปรับปรุงแก้ไขหลักสูตร (สมอ.08) `#/smo` `#/smo-new` `#/smo-view/<id>` · นำเข้าข้อมูลเล่มหลักสูตรด้วย AI `#/import` `#/import-review` `#/import-done` · บริหารรายวิชา `#/course-master` · บริหารบุคคลภายนอก `#/ext-person`

## 1. แนวคิดหลัก

- **คู่มือหลักสูตร** = แบบฟอร์มบันทึกข้อมูลหลักสูตร 1 ฉบับต่อ 1 หลักสูตรต่อ 1 ฉบับปี (เช่น "วท.บ. เทคโนโลยีวัสดุพอลิเมอร์ (ปป.67)") แบ่งเป็น 6 ส่วน: หมวด 0 ข้อมูลหลักของระบบ (ฟิลด์ระบบเดิม SUPREME CUR27 + อาจารย์หลักสูตร) · หมวด 1–4 ตามเล่ม/TOR ข้อ 6.1 · หมวด 5 สถานภาพและการอนุมัติ
- หมวด 5–8 ของเล่มหลักสูตร **ไม่อยู่ในขอบเขต** ฟอร์ม (แต่ระบบ OCL เก็บเป็น Markdown ทั้งเล่มไว้ให้อ่าน/ค้น)
- ข้อมูลอาจารย์และรายวิชา **ไม่พิมพ์ซ้ำ** ดึงจาก "ข้อมูลหลัก": อาจารย์ภายในจาก HURIS · บุคคลภายนอกจากทะเบียนกลาง · รายวิชาจากฐานข้อมูลรายวิชากลาง (CUR23) พร้อม Version
- การเปลี่ยนข้อมูลหลังคู่มือ "ตรวจสอบสำเร็จ" ต้องผ่าน **สมอ.08** เท่านั้น

## 2. สถานะคู่มือหลักสูตร (state machine)

```
[ร่างนำเข้าหลักสูตร] --ส่งให้คณะตรวจสอบ--> [คณะตรวจสอบ] --ตรวจสอบสำเร็จ--> [ตรวจสอบสำเร็จ] --เปิดเผยแพร่ (ส่วนกลาง)--> [เผยแพร่]
       ^                                      |                                   |
       |<---------- ส่งคืนเป็นร่าง ------------+                                   +--แก้ไขผ่าน สมอ.08 เท่านั้น (ข้อมูลถูกล็อก)
```

| สถานะ | ใครแก้ได้ | หมายเหตุ |
|---|---|---|
| 1 ร่างนำเข้าหลักสูตร | ส่วนกลาง / หลักสูตร | มาจากนำเข้าด้วย AI หรือบันทึกเอง |
| 2 คณะตรวจสอบ | ผู้ตรวจสอบระดับส่วนงาน แก้ได้**เฉพาะหมวด 3–4** (PLO/KSEC และ Mapping; โครงสร้างดูอย่างเดียว) หมวดอื่นดูอย่างเดียว | กำหนด 5 วันทำการ · ถ้าพบปัญหาหมวดอื่นกด "ส่งคืนส่วนกลาง" |
| 3 ตรวจสอบสำเร็จ | ไม่มีใครแก้ตรง | ล็อก แก้ผ่าน สมอ.08 |
| 4 เผยแพร่ | ผู้ดูแลส่วนกลางเปิด/ปิด | เปิดได้เมื่อสถานะ 3 เท่านั้น |

ทุกการเปลี่ยนสถานะและการแก้ไขบันทึกใน "ประวัติการแก้ไข" (วันเวลา ผู้ดำเนินการ การดำเนินการ)

การดำเนินการและสิทธิ์ (สร้างแล้วใน R1 POC 22 ต.ค. 2569 · กรณีทดสอบ K-01–K-10)

| การดำเนินการ | จากสถานะ → ไปสถานะ | ผู้ทำได้ | เงื่อนไข |
|---|---|---|---|
| ส่งให้คณะตรวจสอบ | 1 → 2 | admin · central · curator | ตั้งกำหนด 5 วันทำการนับจากวันที่ส่ง |
| ติ๊ก "ตรวจสอบหมวดนี้แล้ว" | อยู่ที่ 2 | admin · faculty | เฉพาะหมวด 3 และหมวด 4 |
| ส่งคืนส่วนกลาง (เป็นร่าง) | 2 → 1 | admin · central · faculty | ต้องใส่เหตุผล |
| ตรวจสอบสำเร็จ | 2 → 3 | admin · faculty | ติ๊กครบทั้งหมวด 3 และหมวด 4 |
| เปิดเผยแพร่ / ปิดเผยแพร่ | 3 → 4 / 4 → 3 | admin · central | |
| แก้ข้อมูลระหว่างสถานะ 2 | – | faculty แก้ได้เฉพาะ PLO · KSEC · Mapping | ส่วนอื่นตอบ 403 |
| แก้ข้อมูลในสถานะ 3–4 | – | ไม่มีใคร | ตอบ 409 "ถูกล็อก แก้ได้ผ่าน สมอ.08 เท่านั้น" (BR-06) · สมอ.08 อยู่ใน R2 |

## 3. User stories

### 3.1 แดชบอร์ดหลักสูตร [mock: dash-cur]

- **US-M1-01** ในฐานะผู้ดูแลส่วนกลาง/ผู้บริหาร ฉันต้องการเห็นจำนวนหลักสูตรแยกตามสถานะ (ร่าง/คณะตรวจ/สำเร็จ/เผยแพร่) กรองตามคณะ ระดับ ปีที่เริ่มใช้ เพื่อติดตามความคืบหน้าทั้งมหาวิทยาลัย
  - AC: KPI 4 ค่า + แถบสัดส่วน · ตารางความคืบหน้ารายคณะ (จำนวนหลักสูตร % ตรวจสอบสำเร็จ ค้างนานสุด) · ความครบถ้วนรายหมวด 0–5 (%) · ตารางหลักสูตรค้างนานสุดพร้อมหมวดที่ยังไม่ครบ และปุ่ม "แจ้งเตือน" · ส่งออกได้
- **US-M1-02** ฉันต้องการแท็บ "วิเคราะห์เชิงสถิติ" `[รายละเอียดยังไม่เห็นใน mock — ถาม]`
  - AC: แท็บมี 3 มุมมองตามคำบรรยายใน mock: ภาพรวม · ข้อมูลสำหรับตอบ อว. · หลักสูตรที่ใกล้ครบรอบปรับปรุง (ปีที่เริ่มใช้ + 5 ตาม BR-08) · กรองคณะ ระดับ ปีที่เริ่มใช้ได้เหมือนแท็บหลัก `[สมมติ: รายละเอียดกราฟรอคำตอบ C1]`

### 3.2 คู่มือหลักสูตรตาม TOR [mock: cur, cur-edit]

- **US-M1-03** ในฐานะผู้ดูแลส่วนกลาง ฉันต้องการรายการหลักสูตรทั้งหมดพร้อมสถานะ ค้นหา (ชื่อ/รหัส) กรอง (คณะ ระดับ ปีเริ่มใช้ สถานะ) แบ่งหน้า เพื่อเข้าไปบันทึก/ตรวจ/ดู
  - AC: การ์ด KPI คลิกเพื่อกรองสถานะ · ปุ่ม "เพิ่มหลักสูตร" · "นำเข้าจากเล่มด้วย AI" · "รายงานคู่มือหลักสูตร (R12)" · ปุ่มท้ายแถวเปลี่ยนตามสถานะ (แก้ไขร่าง / ตรวจสอบ / ดูรายละเอียด)
- **US-M1-04** ฉันต้องการกรอก/แก้คู่มือหลักสูตรทีละหมวด (0–5) มี sidebar แสดงความคืบหน้า (✓ หมวดที่ครบ) ปุ่ม หมวดก่อนหน้า/ถัดไป บันทึกร่าง Preview ส่งให้คณะตรวจสอบ
  - AC: ฟิลด์ตาม data dictionary ข้อ 4 · ฟิลด์ที่มีป้าย "ข้อมูลหลัก" แก้ได้ที่หมวด 0 เท่านั้นและแสดงอ่านอย่างเดียวในหมวด 1 · ฟิลด์ที่มีป้าย "SUPREME" ดึงจากระบบเดิม · ตัวเลือก (เช่น รูปแบบหลักสูตร รูปแบบการสอน) มาจากข้อมูลพื้นฐานที่ผู้ดูแลระบบเพิ่มได้
- **US-M1-05** ฉันต้องการ Preview คู่มือ "แบบเล่มหลักสูตร" (หมวด 3–4) และส่งออก PDF เพื่อเทียบกับเล่มต้นฉบับ
  - AC: Preview แสดงหมวด 3 (PLO · KSEC · ตารางสรุป) และหมวด 4 (โครงสร้าง · รายวิชา · Mapping) ตามลำดับและรูปแบบตารางของเล่ม · PDF ขนาด A4 มีชื่อหลักสูตร ฉบับปี และวันเวลาที่ส่งออก · เนื้อหาตรงกับข้อมูลล่าสุดที่บันทึก รวมการแก้ของคณะ
- **US-M1-06** ในฐานะผู้ตรวจสอบระดับหลักสูตร (curator) ฉันเห็นเฉพาะหลักสูตรที่รับผิดชอบ (อัตโนมัติจากรายชื่ออาจารย์ผู้รับผิดชอบ/สมอ.08) `[สมมติ: อิงตาราง roles ใน mock]`
  - AC: curator เห็นและเปิดได้เฉพาะหลักสูตรที่ตนอยู่ในรายชื่ออาจารย์ผู้รับผิดชอบ/ประจำ (หมวด 0.2) · เปิดหลักสูตรอื่นด้วย URL ตรงได้ 403 · เมื่อรายชื่ออาจารย์เปลี่ยนผ่าน สมอ.08 ที่อนุมัติแล้ว สิทธิ์เปลี่ยนตาม `[สมมติ: มีผลทันทีหลังอนุมัติ]`
- **US-M1-20** ในฐานะผู้บันทึกคู่มือหลักสูตร ฉันต้องการเปิดกลุ่มวิชาในโครงสร้างหมวด 4 เพื่อดู เพิ่ม หรือนำรายวิชาออกจากกลุ่มนั้น โดยเลือกจากฐานข้อมูลรายวิชากลาง หรือสร้างรายวิชาใหม่ [mock: st-courses]
  - AC: แสดงเส้นทางกลุ่ม (หมวดที่ 4 › … › กลุ่ม) Level และหน่วยกิตต่ำสุด/สูงสุดของกลุ่ม · กลุ่มที่เป็นชุดวิชาแสดงคำอธิบายชุดวิชา · ค้นรหัสหรือชื่อรายวิชาในกลุ่ม · "เลือกรายวิชาจากฐานข้อมูลกลาง" แสดงเฉพาะรายวิชาที่ยังไม่อยู่ในหลักสูตร · "สร้างรายวิชาใหม่" ต้องกรอกรหัสและชื่อไทย และถ้ารหัสมีในฐานข้อมูลแล้วให้เลือกจากรายการแทน · รหัสวิชาแสดงเลข Version ต่อท้าย (-1, -2) · เปิดจากสถานะที่แก้ไม่ได้เป็นโหมดดูอย่างเดียว

### 3.3 ตรวจสอบและบันทึก PLO โดยคณะ [mock: fac-plo, fac-plo-edit]

- **US-M1-07** ในฐานะผู้ตรวจสอบระดับส่วนงาน ฉันต้องการรายการหลักสูตรที่ส่วนกลางส่งมาตรวจ (รอตรวจ / ครบหมวด 3–4 แล้ว / ดำเนินการแล้ว) พร้อมวันที่ส่ง ผู้ส่ง กำหนด 5 วันทำการ และความคืบหน้า หมวด 3 หมวด 4
  - AC: เห็นเฉพาะหลักสูตรในสถานะ "คณะตรวจสอบ" ของส่วนงานตน · แต่ละแถวมีวันที่ส่ง ผู้ส่ง วันครบกำหนด (5 วันทำการ ไม่นับเสาร์–อาทิตย์) และสถานะติ๊กหมวด 3 / หมวด 4 · faculty ส่งตรวจเองไม่ได้ (K-09)
- **US-M1-08** ฉันต้องการตรวจและแก้หมวด 3 (PLO/Sub-PLO · KSEC · ตารางสรุป) และหมวด 4 เฉพาะ Curriculum Mapping แล้วติ๊ก "ตรวจสอบหมวดนี้แล้ว" ครบ 2 หมวดจึงกด "ตรวจสอบสำเร็จ" ได้ หรือ "ส่งคืนส่วนกลาง" พร้อมหมายเหตุ
  - AC: หมวด 0 1 2 5 และโครงสร้างหมวด 4 เป็นอ่านอย่างเดียว · ปุ่ม "ตรวจสอบสำเร็จ" ปิดจนกว่าจะติ๊กครบ · แสดงหมายเหตุจากส่วนกลาง

### 3.5 นำเข้าข้อมูลเล่มหลักสูตรด้วย AI (OCL Agent) [mock: import, import-review, import-done]

ขั้นตอน 4 ขั้น: 1 อัปโหลดเล่มหลักสูตร → 2 AI อ่านและสกัดข้อมูล → 3 ตรวจสอบความถูกต้อง → 4 ยืนยันบันทึกเข้าระบบ
