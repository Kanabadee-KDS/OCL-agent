# 03 M3 Skill Transcript

เมนูใน mock: บริหารฐานข้อมูล Skill `#/skill-db` · กำหนดผู้บันทึกแผนการประเมิน Skill `#/skill-assign` · กำหนด Skill ตามหลักสูตร `#/skill-cur` · กำหนดรายวิชาประเมิน Skill `#/skill-map` · บันทึกประเมิน Skill `#/assess` `#/assess-form/<รายวิชา>` · Skill Portfolio `#/portfolio` `#/portfolio-detail/<นิสิต>` · ออกเอกสาร Skill Transcript `#/issue` `#/transcript/<นิสิต>` · สำหรับนิสิต `#/me` `#/my-transcript` · แดชบอร์ด `#/dash-skill`

## 1. แนวคิดหลัก

- ทักษะ 4 ด้าน: **GS** Generic skills (แกนกลาง มศว ทุกหลักสูตรต้องประเมิน) · **SS** Specific skills (หลักสูตรกำหนด) · **E** Ethics · **C** Characters · รหัสเช่น GS1 SS2 E3 C4 · แต่ละ Skill มีชื่อ TH/EN นิยามเชิงปฏิบัติการ (พิมพ์หลังเอกสาร) ขอบเขต (ส่วนกลาง/หลักสูตร) รูปแบบผล (คะแนน 1–5) เครื่องมือ (Scoring rubric / Self-assessment 5 ระดับ) แหล่งที่มา (รายวิชา / สหกิจ-ฝึกงาน / กิจกรรมเสริม)
- เกณฑ์ระดับความเชี่ยวชาญ 5 ระดับจากคะแนน: Novice 0–1.49 · Advanced Beginner 1.50–2.49 · Competent 2.50–3.49 · Proficient 3.50–4.49 · Expert 4.50–5.00
- ลำดับงาน: ฐานข้อมูล Skill → ชุด Skill ของหลักสูตร (แกนกลาง + เลือกจากกลาง + เพิ่มเอง; อนุมัติ 2 ขั้น) → Skill Mapping รายวิชา × Skill ต่อภาค (ร่าง → ส่งอนุมัติ) → อาจารย์ประเมินนิสิตรายวิชา-กลุ่ม (รายชื่อจาก SUPREME) → ยืนยันผล → Portfolio สะสม (ค่าเฉลี่ยทุกรายวิชาที่ประเมิน) → ออก Skill Transcript เมื่อสำเร็จการศึกษา (PDF + Certificate + ลายมือชื่อดิจิทัลจากผู้ลงนามใน SUPREME, TOR 6.12.3–6.12.5)
- เชื่อม M1: ทักษะทั่วไป/เฉพาะใน KSEC ของคู่มือหลักสูตร ↔ GS/SS · AI นำเข้าแนะนำ Skill จากเล่มหมวด 5 ข้อ 2.1 และแผนการศึกษา (ปี/ภาค)

## 2. User stories

### 2.1 ฐานข้อมูล Skill [mock: skill-db]

- **US-M3-01** ในฐานะส่วนกลาง ฉันต้องการเพิ่ม/แก้/ปิดการใช้งาน Skill (รหัส ด้าน ชื่อ TH/EN นิยาม ขอบเขต รูปแบบผล เครื่องมือ แหล่งที่มา) นำเข้าจาก Excel และตั้ง "เกณฑ์ระดับความเชี่ยวชาญ" และ "ระดับการศึกษา/ปีที่เข้าศึกษา" ที่ใช้
  - AC: แท็บ รายการ Skill / เกณฑ์ระดับ / ระดับการศึกษาและปีที่เข้าศึกษา · กรองขอบเขต

### 2.2 กำหนดผู้บันทึกแผนการประเมิน Skill [mock: skill-assign]

- **US-M3-02** ฉันต้องการกำหนดต่อหลักสูตร: ผู้รับผิดชอบ (>1 คน) ขอบเขต (ทั้งหลักสูตร / รายวิชาที่ระบุ) และสิทธิ์ (เพิ่ม Skill ในฐานข้อมูล · Mapping · ส่ง Mapping เข้าสู่การอนุมัติ · อนุมัติ Skill/Mapping) และเห็น KPI หลักสูตรที่กำหนดแล้ว/ยังไม่กำหนด

### 2.3 กำหนด Skill ตามหลักสูตร [mock: skill-cur] (ป้าย "ใหม่")

- **US-M3-03** ในฐานะผู้กำหนด Skill ของหลักสูตร ฉันต้องการจัดชุด Skill ของหลักสูตร = แกนกลาง (บังคับ) + เลือกจากฐานข้อมูลกลาง + เพิ่มเอง แล้วส่งอนุมัติ (ผู้กำหนด → คณะ) · ภาพรวมทุกหลักสูตร: จำนวน GS/SS/E/C ที่มา สถานะ (ยังไม่กำหนด / ร่าง / รออนุมัติ / อนุมัติแล้ว)

### 2.4 กำหนดรายวิชาประเมิน Skill (Skill Mapping) [mock: skill-map]

- **US-M3-04** ฉันต้องการเลือก ภาค/ปี → หลักสูตร → ชุดวิชา → รายวิชา แล้วกำหนด Skill ที่ประเมินในรายวิชานั้น (เลือกจากชุด Skill ของหลักสูตร; กำหนดทั้งชุดวิชาด้วย Skill เดียวกันได้) เห็น KPI รายวิชาในหลักสูตร / กำหนดแล้ว / จุดประเมิน (รายวิชา × Skill) / Skill ที่ยังไม่มีรายวิชา · สรุปความครอบคลุม · คัดลอกจากภาคก่อน · บันทึกร่าง · ส่งอนุมัติ

### 2.5 บันทึกประเมิน Skill [mock: assess, assess-form]

- **US-M3-05** ในฐานะอาจารย์ผู้สอน ฉันต้องการรายการรายวิชา-กลุ่มที่ต้องประเมินในภาค (Skill ที่ต้องประเมินจาก Mapping · จำนวนนิสิต · ความคืบหน้า · กำหนดส่ง · สถานะ ยังไม่ประเมิน / กำลังประเมิน / รอยืนยัน / ยืนยันแล้ว)
- **US-M3-06** ฉันต้องการให้คะแนนนิสิตแต่ละคน (0–5 ต่อ Skill) ในตาราง มี rubric ประกอบ "ให้คะแนนเท่ากันทั้งกลุ่ม" ดาวน์โหลดแบบฟอร์ม Excel / นำเข้า Excel บันทึกร่าง และ "ยืนยันผลการประเมิน"
  - AC: รายชื่อนิสิตและกลุ่มเรียนจาก SUPREME · ผลที่ยืนยันแล้วเข้า Portfolio ทันที

### 2.6 Skill Portfolio [mock: portfolio, portfolio-detail]

- **US-M3-07** ในฐานะอาจารย์ที่ปรึกษา/อาจารย์ ฉันต้องการค้นหานิสิต (หลักสูตร รหัสปีเข้า) เห็นคะแนนเฉลี่ย GS/SS/E/C ระดับรวม และหน้ารายคนที่มี Radar 4 ด้าน คะแนนราย Skill ตารางสะสมรายภาค (ปี1/1 … ปี4/2) ที่มาของคะแนนต่อ Skill (รายวิชา + สูตรเฉลี่ย) สถานที่ฝึกประสบการณ์ · ส่งออกรายชื่อ · รายงานผลรายบุคคล

### 2.7 ออกเอกสาร Skill Transcript [mock: issue, transcript] (ป้าย "เสนอเพิ่ม")

- **US-M3-08** ในฐานะส่วนกลาง ฉันต้องการรายการผู้สำเร็จการศึกษาตามปี/หลักสูตร แยก พร้อมออก / ผลประเมินไม่ครบ (ต้องให้อาจารย์ประเมินเพิ่ม) / Ethics ไม่ผ่าน (ส่งหลักสูตรพิจารณา) / ออกแล้ว เลือกทั้งหมดที่พร้อม ดูตัวอย่าง "สร้างเอกสารและส่งลงนาม" และมีแท็บ ทะเบียนเอกสารที่ออก (R09) และ เงื่อนไขการออกเอกสาร
  - เอกสาร: เลขที่ ST-ปปปป-nnnnnn · ชื่อ รหัส หลักสูตร คณะ วันเข้า/จบ · ตาราง GS SS C E (คะแนน ระดับ) · Radar · สถานที่ฝึกประสบการณ์ · QR/URL ตรวจสอบ · ลายมือชื่อดิจิทัล ผู้ลงนาม ตำแหน่ง วันที่ · หน้า 2 นิยามทักษะ
  - Ethics แสดงเป็น S/U ในการออกเอกสาร (mock: "S ทุกข้อ", "U (E2)") ขณะที่ Portfolio แสดงคะแนน `[ถามเกณฑ์แปลง]`

### 2.8 สำหรับนิสิต [mock: me, my-transcript]

- **US-M3-09** ในฐานะนิสิต ฉันต้องการเห็น Portfolio ของตนเอง (เหมือน 2.6 รายคน) และ Skill Transcript ฉบับร่าง (ยังไม่ลงนาม) คัดลอกเลขที่เอกสาร ดาวน์โหลด PDF เมื่อออกแล้ว

### 2.9 แดชบอร์ด Skill [mock: dash-skill]

- **US-M3-10** ฉันต้องการเห็นต่อภาค: รายวิชา-กลุ่มที่ต้องประเมิน · % นิสิตที่ประเมินครบ · รอผู้สอนยืนยัน · ยังไม่เริ่ม · Transcript ที่ออกแล้ว/พร้อมออก/ข้อมูลไม่ครบ · ความคืบหน้าต่อคณะ · รายวิชาที่ค้างนานสุดพร้อม "แจ้งเตือน"

## 4. ข้อมูลที่ต้องขอ

ฐานข้อมูล Skill ปัจจุบัน (รายการ GS/SS/E/C + rubric) · ทะเบียนนิสิตและการลงทะเบียน (SUPREME) · ผู้มีอำนาจลงนามและรูปแบบลายมือชื่อดิจิทัล · แบบ Certificate · เกณฑ์แปลง Ethics เป็น S/U
